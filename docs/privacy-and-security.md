# Privacy and security

The public BI release is available at https://github.com/LeoBobadilha/project-vortex-bi-showcase. Its companion website source is at https://github.com/LeoBobadilha/project-vortex-portfolio.

The public allowlist contains approved portfolio-level aggregate CSVs, public report definitions and measures, original diagrams, redacted chart exhibits, genuine Desktop screenshots and documentation. It excludes private PBIP/model content, row-level ledgers, raw M5 archives, proprietary strategy source or exact signal rules, credentials, broker/account data and internal operational paths.

No external Power BI report is embedded. The public model has no broker, account or live-market connection. Its benchmark is a historical backtest; no Paper Live P&L or live-account performance is claimed. The website is deployed at https://leobobadilha.github.io/project-vortex-portfolio/ through GitHub Actions (successful run 42029504199). Its current gallery contains only the clean Executive Overview preview; the complete Power BI gallery is withheld pending recaptures.
