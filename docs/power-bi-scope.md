# Power BI Report Scope

The published public report is an independent 14-page PBIP. It contains a nine-table semantic model, 24 DAX measures, Power Query transformations, approved portfolio-level aggregate data and anonymized embedded case-study images.

Power BI Desktop 2.159.883.0 previously opened the named `ProjectVortex-Public` PBIP. After configuring the local `data/` root and refreshing, all 14 pages rendered. Pixel review later found overlays on the saved screenshots for pages 04-11. The published main retains six clean screenshots (01-03 and 12-14) and withholds the contact sheet; eight genuine recaptures remain outstanding. See `screenshot-qa-2026-11-05.md`. The screenshots do not define page count or alter PBIP contents.

The report presents P6+SIZE+CE (PSC) and the P6 baseline separately. The declared Vortex_Navy custom theme is embedded in the public PBIR resources. It does not include private trade-level facts, raw M5 bars, exact case dates or prices, individual case outcomes, strategy rules, brokerage data or Paper Live P&L. The monthly drawdown visualization is an explicitly labeled aggregate proxy.
